# Crossfield Tier-1 live preview

This is a visual-only proxy preview of the existing Crossfield site.

It deliberately preserves upstream:
- copy and headings
- services and service names
- navigation labels
- company positioning
- logo artwork
- routes, forms and links
- existing photography sources

Only the presentation layer is injected:
- composition
- typography hierarchy
- spacing and section rhythm
- image treatment
- map framing
- hover/reveal motion
- responsive editorial grids

Railway environment:
- UPSTREAM_ORIGIN
- UPSTREAM_PREFIX=/crossfield-website/
- REPLIT_SID (kept out of this public repository)
